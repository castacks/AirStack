# NatNetClientSDK (reference only)

Local copy of the OptiTrack NatNet 4.4 SDK samples and headers for **protocol development**.

- **Not** installed by the Isaac extension wheel
- **Not** redistributed by AirStack (OptiTrack license applies)
- Use for wire-format reference: `NatNetSDK/include/NatNetTypes.h`, `Samples/PacketClient/PacketClient.cpp`

Production robot client uses `libNatNet.so` via `airstack setup --natnet` in [`natnet_ros2`](../../../../robot/ros_ws/src/perception/natnet_ros2/).
