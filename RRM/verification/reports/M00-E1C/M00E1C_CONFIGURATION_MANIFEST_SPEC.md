Store originals as immutable release with byte count/SHA-256 and signed owner approval; separately preserve the manifest digest. Archive externally with independent receipt/retention owner; do not store large binaries/images/raw streams in Git. A hash is integrity evidence, not correct configuration or REC-01 survival.

All completed/failed/aborted/incomplete/setup starts remain counted with original ID and partial evidence; never overwrite/substitute. Same per-pair cache/scene/build/resource identities are required; no shared deletion or hidden warm-up. Any source/image/plugin/stage/security/host/clock change opens a new candidate revision and review, never silently edits sealed evidence.
