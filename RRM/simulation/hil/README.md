# HIL planning boundary

No HIL hardware or firmware was started in M00. EXT E5 prefers H-a Gazebo Classic HITL with target MCU; H-b SIH is an alternative; H-c Pegasus HIL remains experimental. D5 class AV is preserved. Compare H-a first to CFG-SIL-02; no claim of F00 dynamics equivalence or real sensor performance.

Entry requires SIL exit, agreed board/firmware binary/companion/interfaces, complete parameter deltas, independent recorder supervision on the companion and E9-T1/T5 decisions. Record MCU scheduling/load/overruns and communications timing without inventing thresholds. The proposed 30 trials per category and ≤5 ms skew remain pending, not M00 acceptance.
