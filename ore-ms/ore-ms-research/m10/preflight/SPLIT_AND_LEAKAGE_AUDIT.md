# Split and input-isolation audit

A realization owns its 27 interventions, including paired detector noise, geometry and the related process states. IDs 0–127 are development, 128–255 calibration and 256–511 holdout. Opportunity IDs are permuted joins. The independent audit verified all 512 ID groups and all 13,824 joins, with zero cross-split or duplicate opportunities.

The frontend executable reads only the observation directory. The CSV reader rejects extra fields. The candidate function receives detector codes, masks and approved acquisition metadata. The loader keeps ID and split outside the candidate function and appends the ID only to output rows. The calibration process receives a different staging directory containing four development/calibration tables. The separate evaluation command checks the hashed calibration receipt and method hashes before loading holdout labels. The replay package contains the holdout, so lock status describes the procedure and provenance. A replay operator has access to its labels. The public generator and seeds make opportunity IDs reproducible, so integrations must keep join IDs, generator and scoring files outside the predictive feature boundary.

Standalone inference produced the same bytes without any scoring store and with an adversarially modified truth file next to it. It rejected seven forbidden input columns covering visibility, oracle output, future state, case, simulator range, first-hit identity and target position. All 512 instances of each of the blind-future, matched-distractor, unknown-range and unknown-material controls produced the same outputs as their matched reference after excluding opaque join IDs. The first two also had identical approved metadata and detector arrays. The blind intervention changed all 512 future burdens and preserved all current burdens. An injected 2001 ms observation in the standalone test was excluded.

The 1900 ms LWIR control is measured on a static scene within the acquisition window, isolated as a clock failure. Declared registration failure gates LWIR. The undeclared three-pixel shift is neither recovered nor passed to the frontend as hidden truth. The issued range is the declared 10 m experimental plane, shared across controls including negatives. Unknown range remains blank. Material/source qualification is carried as a validity flag. Neither constraint is needed by the full-frame contrast frontend.
