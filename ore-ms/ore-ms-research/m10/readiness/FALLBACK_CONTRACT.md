# Requirements for a future decision contract

This is a specification for evaluation after separate authorization. The future implementation must expose one outcome among joint adaptive, RGB-only, LWIR-only, fixed nonadaptive, and abstained. Every outcome states which evidence was admitted and why. A supported visible-target localization additionally requires a task confidence or calibrated score and usable spatial support.

1. **Check the frame contract.** Validate acquisition/decision time, coordinate reference, calibration versions, freshness, numeric validity, support and valid/rail masks. Failed registration or intersensor timing disallows joint use. A single modality can remain eligible only with its own independently qualified geometry and task frontend.
2. **Check the context contract.** Use burden or spectral forecasts only if their required nuisance and regime constraints are pinned. A declared unsupported process or materially uncertain source disables the associated adaptive context. Missing M07/M08/M09 eligibility or a narrow interval cannot establish safety. Where mismatch is hidden, constrain the scope of claims and measure blind failures explicitly.
3. **Check task qualification.** Both eligible modalities may proceed to a matched experiment. If one is unusable, a single-modality path requires prospective task evidence for that operating cell. If adaptation has insufficient independent calibration, use the strongest qualified fixed comparator with declared coverage controls. If neither the alternative nor the fixed comparator is qualified, abstain.
4. **Keep environmental fallback separate.** A labeled prior for the fixed optical path can remain valid with no current target evidence. It does not authorize a location or an absence declaration. A known fully hidden target, failed association, missing support or unsupported input scope requires no supported localization unless independently task-qualified evidence restores support.
5. **Record all opportunities.** Log status, per-channel reasons, valid support, input metadata, context horizon, warning exposure, baseline/fallback status and abstention reason. Preserve cases where the apparent gate missed a shift. Do not infer that a modality is task reliable from transmission alone.

## Proposed interface

**Input** consists of synchronized RGB/LWIR codes, masks and acquisition timestamps, decision time and sensor age, calibration and valid scope references, independently available search/range or geometry constraints, known material/source context with uncertainty, and optional issue-time-only M07/M08/M09 marginals and their provenance. Qualified per-modality task outputs may carry candidate locations and calibrated task scores. Missing, stale, censored and unsupported are separate statuses.

**Output** consists of visible-target pixel location if issued, task confidence and calibration scope, admissible modality set, decision class, and reasons. An abstention records no location. The interface does not output physical occupancy or future visibility. The isolated scorer receives hidden target support, actual conditions, task labels and eventual outcomes. The future policy may not receive truth, regime intervention IDs, oracle state or a future timestamp.
