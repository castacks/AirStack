# M03 frozen protocol

ORE-MS-EXP-PER-001-M03-R1 authorizes thermal transfer, detector modeling and controlled verification. M01 and M02 are conditionally accepted by this directive. Start from `2b0adc94e3dbd1fd99e56acdec8eef33957dbfc1`. Original specification §§3, 5–6 and the [roadmap mandate](../RESEARCH_ROADMAP_MANDATE.md) govern the work. The [frozen configuration](scene.json) defines a sparse, one-factor-at-a-time matrix plus declared interactions and static visibility controls. No synthetic case is assigned a weather or hardware label.

Use 280/300/320/340 K independently for target and background, ε=0.2/0.5/0.8/1 and gray τ=0/0.25/0.5/0.75/1. The τ=0 fixture is the opaque-limit homogeneous source, not a finite-coefficient path. Vary effective reflection temperature, specified spectral environmental radiance, path temperature, layer order and wavelength-varying emissivity/absorption/response. Use a correctly visible crossover sweep with fixed background and target ε=0.5 plus equal-temperature and fully opaque-path controls. The static hidden-target case selects a designated foreground by a supplied flag. No geometry is inferred. Compare noiseless, noisy and limited sensor responses. Retain all case results.

For visible cases record the signed target-minus-background band radiance, normalized contrast, and whether the absolute difference is within max(one detector LSB, 2√2σ). The threshold is an illustrative discrimination scale for independent equal detector noise, not a confidence guarantee. Locate crossover sign changes only within the designated unclipped sweep and interpolate within the bracketing samples. Record raw spectral and detector components, pre-detector band values, noiseless code, every measured code, clipping, per-ray sample standard deviation and radiance-domain RMSE. A hidden target has no visible target contrast; record foreground/background contrast separately.

## Frozen acceptance criteria

| ID | Evidence and criterion |
|---|---|
| V01 | Planck at 8/10/14 µm and 280/300/320/340 K against a 45-digit Decimal reference. Relative error ≤2e-12. Positive and strictly increasing with T at fixed band wavelengths. Broad tails remain finite and nonnegative. Wien peak for 300 K sampled at 9.5/9.659/9.8 µm is largest at 9.659 µm. |
| V02 | Log-wavelength Simpson integral over 0.05–10000 µm at 2048 and 4096 intervals against σT⁴/π from the CODATA Stefan–Boltzmann constant. At each level and temperature relative discrepancy ≤2e-8 and relative refinement difference ≤2e-9. The broad interval contains the thermal peak and captures the far tail at these temperatures. |
| V03 | For ε=0 boundary equals reflection, for ε=1 it equals Bλ(T), and for equal Bλ and reflected radiance it is invariant to ε. For all five gray τ fixtures check the analytical isothermal solution. Absolute plus relative tolerance 2e-12. |
| V04 | Compare spectral layered transfer at 8/10/14 µm against a continuous ODE solved separately in each constant layer with RK4. The 128/256-step-per-layer references agree within 2e-8 W·m⁻²·sr⁻¹·µm⁻¹ and the 256-step value matches the exact layer solver within 2e-8. Reversing nonisothermal layers preserves transmission and changes path radiance. |
| V05 | On the frozen combined target case compare 48/96/192 trapezoids to alternate Simpson at 1536/3072 intervals. Simpson references agree within 2e-8 W·m⁻²·sr⁻¹, 192-interval error ≤2e-4, and grid-halving ratios 3.7–4.3. At the detector, unsaturated quantization error ≤0.5 LSB, seeded noise repeatable with alternate seed sensitivity, Gaussian input variance within 5% and mean within 0.05σ on 8192 fixed samples, exact low/high code bounds. |
| V06 | All configured cases and samples retained, identity and opaque-limit matches flagged without occlusion, designated scan has one sign-change bracket, and hidden target has no assigned target contrast. The radiance-weighted combination, visible/noisy metric records and component closure are cross-checked from raw CSV. |
| V07 | Replay deterministic and seeded captures in two fresh processes with byte identity. Verify the archived M01/M02 manifests, rerun prior regression suites, and verify unchanged task catalog and dependencies. |

The tolerances bound numerical accuracy under smooth synthetic fixtures. V01/V03 allow double-precision rounding. V02 accounts for the deliberately finite tails. V04/V05 require independent refinement checks. A result that fails a frozen criterion remains recorded.
