# M02 visible-light forward model

A static scene supplies Lambertian reflectance ρ(λ) in [0,1] and incident spectral irradiance E(λ) in W·m⁻²·nm⁻¹. The boundary spectral radiance is L₀(λ)=ρE/π in W·m⁻²·sr⁻¹·nm⁻¹. The configuration key beginning with `illuminance_spectrum` stores **spectral irradiance** in the units in its suffix. Its legacy name has no photometric interpretation. A scene illumination scale changes E independently of reflectance, extinction, and the prescribed illumination of the medium. These controls represent distinct physical inputs.

Let s increase along the ray from the surface toward the camera. Absorption a(λ,s) and scattering b(λ,s) have units m⁻¹. Out-scattering contributes b to extinction κ=a+b, so transmission is T(λ)=exp(−∫κ ds). Each coefficient is sampled from k(λ)=k(550 nm)(550 nm/λ)^p, using independent prescribed powers for absorption and scattering. These values are synthetic. They represent neither retrieved aerosol coefficients nor a measured visibility range.

The source of in-scattering per metre is j=b∫P(θ)L_inc dΩ. Each layer approximates the integral with a prescribed incident spectral radiance and a single angular bin of solid angle ΔΩ, evaluated at its representative cosine. The isotropic phase is 1/(4π) sr⁻¹. The Henyey–Greenstein alternative is (1−g²)/[4π(1+g²−2g cosθ)^(3/2)] sr⁻¹. g=0 recovers isotropic scattering. The fixed incident field contains no self-consistent feedback, shadowing or additional scatter events. For κ>0 a layer of length d advances intensity as L_out=e^(−κd)L_in+(j/κ)(1−e^(−κd)). A zero-optical-depth segment transmits unchanged. The code composes the source contribution in order and computes direct transmission from summed depths. Reversing unequal layers preserves direct transmission and may change the path term. Smooth media can be approximated by midpoint-sampled slabs. The verification uses a manufactured case to measure convergence.

For each channel the detector projects direct and path radiance separately with ∫R_c(λ)L(λ)dλ. R is a dimensionless triangle of unit peak in each configured band. It spans a different portion of the visible spectrum for R, G and B with overlap. This is an illustrative, reproducible relative-response approximation for a linear detector. It does not represent a specific camera, CIE observer, color space or quantum efficiency. The product of the linear interpolants is quadratic per interval and is integrated analytically. Boundary spectrum and band radiance remain separate from code values. The tests bound interpolation-integral arithmetic and manufactured spatial discretization. They do not establish an accuracy bound for the underlying continuous spectral curves or hardware.

A scalar gain in electrons per W·m⁻²·sr⁻¹ maps band radiance to a mean detector charge. Configurable Gaussian read noise has variance σ_read² and the optional Gaussian shot approximation has variance equal to the mean electrons. Variances add under independence. Noise is applied before clipping to zero/full well and rounding to a configurable linear code, with ties to even. The approximation can misrepresent low photon counts and suppress residuals at saturation. The output records upper clipping. There is no calibration, color processing, dark current, PSF, rolling shutter or demosaic. A fresh seeded PRNG is used per arm, so runs with matching seeds and stochastic terms reuse paired random draws.

## Metrics

Michelson contrast uses mean light and dark codes per channel. The same contrast ratio can rise when attenuation releases sensor saturation. Equivalent input radiance RMSE converts observed codes back with the nominal gain and compares to the clear **pre-detector** band radiance. It includes detector clipping and quantization. The detector SNR is 20 log₁₀(RMS(case-specific noiseless codes)/RMSE(observed codes, noiseless codes)). It is undefined if either term vanishes and can rise when clipping suppresses residuals. SSIM uses a fixed normalized average of the three linear codes, population statistics in uniform 11×11 valid windows, K₁=0.01 and K₂=0.03 on range 1. This is a stated local-window variant applied to aligned images. Its digital reference can itself clip and a brightness increase can improve SSIM while reducing contrast.

## Validity domain

The forward model describes direct transport and an approximate single-scattering source, using prescribed layers and illumination. The maximum scattering optical depth and Poisson proxy 1−e^(−τ_s)(1+τ_s) indicate where repeated interactions may matter in a fixed straight-path idealization. They are neither measured multiple-scattering probabilities for the detector nor error bars. The thick arm exposes a limit of the approximation. It does not qualify fog, rain, smoke, physical calibration, or transfer to an operational camera. No dynamic geometry, LWIR extension, learned inference, fusion or prognostics were implemented.
