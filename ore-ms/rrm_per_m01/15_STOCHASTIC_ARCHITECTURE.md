# Future stochastic architecture

Define a latent state with separately typed geometry, illumination, temperatures, spatial medium fields, window throughput and sensor health. Each state component carries units, spatial support, timestamps and uncertainty. Adapt the M01 forward observation functions behind a common likelihood interface. Keep geometric occlusion as a ray-level latent or known mask and model model-discrepancy terms separately from read noise. Where modalities share weather or timing effects, use common state variables and a justified residual correlation model.

Start with persistence and an AR(1) medium state before moving to switching regimes, Gaussian fields or stochastic differential equations. Define observation sensitivity and distinguish weakly observable states, such as depth/extinction confounds, before fitting. Compare Kalman variants and particle filters on matched scenarios. Propagate posterior draws to horizon-indexed observable-area, contrast and failure probabilities. Log truth alongside predictions only in simulation and scoring. Experiments should predefine reference targets, data splits, metrics and stopping decisions. Implementation awaits authorization.
