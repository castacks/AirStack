# MS² broader-range development protocol

Frozen intent, 2026-11-02; parent 1a86a6f0b. EXP114.

The question is whether previous failures arose from short, narrow and unbalanced testing. Use only already-exposed MS² recordings: day _2021-08-06-11-23-45, night _2021-08-13-21-18-04, rain _2021-08-06-16-19-00. Reserve recordings remain unopened. For each recording with N source groups, take exactly 100 consecutive groups at starts 1, 1+floor(N/3), 1+floor(2N/3). No pixel, support or pose-error screening may change these IDs. These are separated windows within three recordings, not nine independent recordings or 891 independent samples.

Use the existing native MS² adapter and named thermal producer replay, original RGB and thermal checkpoints, fixed geometry admission, count/cell/fraction controls, information-rank sensitivities and fixed experts. No training, threshold search, architecture selection or adoption. Capture observer off/on; active arrays, masks, native poses, events and original decisions must match exactly. Only the previously declared inactive diagnostic fields (match//obs2_covTc and endpoint1 local-depth variance before/after) may differ, with all drift retained and strict all-bits status separately reported.

Source input acquisition may use preserved full TAR and bzip2 block indexes. Validate current HTTP206 exact ranges, archive size, TAR header name/size/checksum, source PNG schema and archived overlap hashes. This verifies selected members, not the current complete archive SHA. Indexes and historical full hashes remain provenance. Intake indexed_bzip2 is isolated from the scientific runtime.

For a qualified provided-reference comparison, common coordinates are rectified RGB-left optical coordinates. Official calibration specifies NIR-left to RGB-left and NIR-left to thermal-left transformations (translations in mm). Thus E_RGB_from_THR = E_RGB_from_NIR inverse(E_THR_from_NIR); compose with the existing optical-from-NED rotation for native camera deltas. Common time intervals are recorded RGB-left times; thermal motion/information use the existing declared constant-twist interval transport. This does not verify physical exposure clocks.

Official RGB odometry is interpreted as camera-to-sequence-initial pose, matching the official loader convention. Score consecutive selected source IDs using inverse(P_i) P_j. Matrices with rotation orthogonality/determinant errors <=1e-5 may be projected by SVD to remove serialization roundoff, with correction magnitudes recorded; larger defects, missing/nonfinite labels are unscored. Native predictions remain retained. An inverse-pose convention sensitivity must be separately labeled, never selected by favorable scores. Labels stay outside native inference and fixed decisions. Report label coverage separately from native support, per-record/window outcomes and both-supported winner balance. Source reference quality, camera calibration uncertainty, preprocessing/checkpoint provenance, within-window correlation and training overlap remain limitations.
