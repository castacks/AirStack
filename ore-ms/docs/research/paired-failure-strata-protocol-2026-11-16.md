## Feature lock and fixed strata

Extract the following for every learned sensor row without loading score files:
accepted match count; cheirality inlier count; inlier/match fraction (null with
zero matches); minimum source/target gray p05–p95 range; minimum endpoint gray
standard deviation. Reuse existing per-image qualification values without new

not radiometric temperature or directly comparable physical exposure. Solver

and source/target times differ; compare each camera's distributions descriptively.
Freeze all source/config/input pins and lock extracted features before label join.

Fixed cohorts: both-camera rotation≥2° separately atR≤1° andR≤5°; paired
translation≥1cm at jointR≤5°/directed-t≤15°. Every cohort anchor receives exactly
