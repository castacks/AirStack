If automatic PSC submission fails due to SSH authentication prompts (like Duo MFA), you can manually submit a request using your OSMO terminal:

    RRM_PSC_USER=oabolade bash scripts/rrm_psc_bridge_manual.sh /root/AirStack/.rrm-artifacts/command-requests/<REQUEST_ID>
  3. Reload history above once the script finishes to view and approve the result.
