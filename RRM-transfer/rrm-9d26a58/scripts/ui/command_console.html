Manual PSC Submission

If automated submission cannot pass PSC Duo MFA, use the OSMO terminal. The helper submits once and immediately prints the PSC job ID; it does not wait for inference.

  1. Copy the Request ID from history.
  2. Submit once:
    RRM_PSC_USER=oabolade bash scripts/rrm_psc_bridge_manual.sh /root/AirStack/.rrm-artifacts/command-requests/<REQUEST_ID>
  3. On PSC, wait until squeue -j <JOB_ID> shows no row.
  4. Fetch once:
    RRM_PSC_USER=oabolade bash scripts/rrm_psc_fetch_result.sh /root/AirStack/.rrm-artifacts/command-requests/<REQUEST_ID> <JOB_ID>
  5. Reload history. A valid single-navigation result is reviewable; an unsupported/multi-action model output is shown as Candidate rejected and never dispatches the drone.
